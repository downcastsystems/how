# Howard of War prototype

Build an original browser-based 3D arena fighter with Three.js and TypeScript. The references guide the atmosphere and combat, without importing God of War assets. Howard is a stylized, muscular Chinese man around 50 with glasses and graying hair.

## Acceptance checks

- One large temple arena with four indestructible gates; enemies arrive in endless waves with increasing counts, health, and damage.
- Keyboard and standard Xbox gamepad support, including menu navigation and restart.
- Two quick swords, jump and aerial attacks, a forward heavy axe slam, and invulnerable dodge rolls. Neutral dodge selects a safe reachable direction away from monsters.
- Visible enemy attack warnings, damage feedback, combo counter, kill count, health, wave progression, and a complete death/restart loop.
- Original procedural 3D environment and animated characters, shadows, fog, attack effects, sound, and responsive HUD.
- Focused combat tests, production type check/build, browser rendering and interaction checks, and final code review.

## Boundaries

Single-player desktop prototype. No multiplayer, copied commercial assets, photorealistic likeness, or external service. Models and animations are created procedurally. Physical controller hardware needs a user check if unavailable locally.

## Completion

All implementation and automated acceptance checks completed. Browser review confirmed first-wave completion, the harder second wave, aerial combat, neutral dodge, pause, restart, and defeat. See VERIFICATION.md. Physical controller validation remains a user hardware check.
